# AZ9 Digital
Arabic-first bilingual landing page for AZ9 Digital.

## Files
- `index.html`: page structure and Arabic/English content
- `styles.css`: responsive styling and multicolor 3D-inspired icon tiles
- `script.js`: mobile navigation, demo assistant interactions, and project email draft
- `assets/az9-mark.svg`: lightweight vector logo

## Run locally
Open `index.html` in a browser. No build command is required.

## Deploy
Use Render Static Site or Cloudflare Pages with this repository. Publish/root directory: `/` (or the repository root), build command: empty.

## Before production
- The AI assistant is a demo only; no AI provider is connected.
- The contact form generates a local copyable request summary. It does not transmit user data to a server. Connect a verified form/email service before accepting leads online.
- The design uses Google Fonts when online and falls back to system fonts.
- Statistics or customer testimonials should not be added unless verified.
